# Security Policy

NeuroABR is research software for ABR waveform analysis. Do not commit identifiable patient data, clinical recordings with identifiers, credentials, or restricted datasets.

Do not publicly disclose sensitive data or exploitable details. Contact the maintainer privately through the GitHub profile.

Relevant reports include unsafe file parsing, malicious CSV/data handling, dependency vulnerabilities, workflow/CI security issues, and unintended disclosure through reports or exports.
